# Хаммурапи (консольная игра на C++)

Учебный проект: клон игры «Хаммурапи» по заданию курса.

## Отличия геймплея
- Вопроса про еду нет: каждый год автоматически списывается n бушелей на жителя.
- Посев вводится в бушелях (0.5 бушеля на акр); излишек пропадает.
- «Продать землю» спрашивается, только если «купить» = 0.
- Порядок года: торговля → посев → урожай → крысы → еда → голод (>45% = поражение) → приезжие → чума.
- В оценке условия объединены через «или».
- P и L считаются как средние за все раунды.
